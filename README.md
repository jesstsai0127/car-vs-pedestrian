# 車 vs 路人：黑色幽默碰瓷模擬器

> 一款關於「1.0 秒法律灰色地帶」的雙角色非對稱策略遊戲。你可以當謹慎防禦的**駕駛**，也可以當精算時機的**碰瓷路人**——兩種身份、兩套存檔、兩種完全相反的樂趣。純屬黑色幽默諷刺，博君一笑。

以 HTML5 Canvas 打造、支援 PC 鍵盤與手機觸控的網頁遊戲，目標是開啟即玩、免安裝。
> ⚠️ **目前為開發中專案**：核心遊戲邏輯（判決、物理、存檔等）已完成，但**可實際遊玩的畫面尚未做好**，還不能開啟遊玩。詳見文末〈開發狀態〉。

---

## 這遊戲在玩什麼？

路上發生車禍時，到底是誰的錯？法律有一條模糊界線：**路人踏進車道超過 1 秒才被撞，算駕駛反應不及；不到 1 秒就被撞，算路人自己衝出來碰瓷。** 這 1 秒的攻防，就是整個遊戲的核心。

- 當**駕駛**：你要在限時內安全開到目的地，看路況、打對方向燈、該煞車時煞得住，盡量別撞到那些故意衝出來的人，否則賠到破產。
- 當**路人**：你要看準車速與駕駛反應，卡進車道後**撐過關鍵的 1 秒**——只要你在車道裡待超過 1 秒才被撞，駕駛就算「反應不及」得賠你一大筆；但撐得不夠（不到 1 秒就被撞）會被判你自己危險亂衝、反而倒賠修車費，跳太早則被駕駛煞停、白跑一趟。

## 兩種身份，兩種玩法

### 🚗 駕駛模式（防禦性駕駛）

**目標**：限時內開到終點，且結算後金錢不為負（撞了人、賠償之後，錢包還守得住）。

**操作**：
| 動作 | PC 鍵盤 | 手機 |
| :--- | :--- | :--- |
| 加速 | ↑ / W | 加速踏板 |
| 煞車 | ↓ / S / 空白鍵 | 煞車踏板 |
| 左 / 右轉方向燈 | ← / → 或 A / D | 儀表板方向燈鈕 |
| 喇叭 | H | 喇叭鈕 |

**要注意的規則**：
- **導航一定要打對方向燈**：路口指示左轉你就得開左轉燈，指示直行就別亂打燈。打錯或不打 → 該關重來（不扣錢、不傷車），但**同一關連錯 3 次會被降回上一關**。
- **喇叭能定身路人**：對 20 公尺內的路人按喇叭，能讓他愣住約 0.25 秒起（升級喇叭可延長），阻止他假摔。
- **撞到人會上法庭**：畫面凍結、跳出判決書，依「1 秒規則」算你要賠多少、對方扣多少血、你的車損多少。

### 🚶 路人模式（碰瓷業者）

**目標**：在一關內，靠假摔累積騙到指定金額的賠償金。

**操作**：先點選路邊的**預備跳出點**，再抓準時機按「跳出 / 假摔」衝進車道。

**要注意的規則**：
- **撐過那條 1 秒線**：從你踏進車道到被撞，只要**超過 1 秒**，駕駛就被判反應不及、全責賠你——而且在車道裡待越久，責任越偏向駕駛、你拿得越多。
- **撐不夠或跳太早都吃虧**：不到 1 秒就被撞 → 判你自己危險跳出，反倒賠修車罰金；跳太早 → 被駕駛及時煞停、沒撞成，白費一次。
- **高級場景要門票**：好賺的場景（豪宅區、商業街）要你的總資產達到門檻才能進，錢不夠就進不去。

## 法庭怎麼判？（核心規則）

撞擊發生後，系統用「路人踏進車道」到「發生碰撞」的**時間差**判責任：

| 時間差 | 判決 | 結果 |
| :--- | :--- | :--- |
| **明顯超過 1 秒**（約 1.03 秒以上） | 駕駛反應不及，**駕駛全責** | 駕駛賠錢給路人 |
| **明顯不到 1 秒**（約 0.97 秒以下） | 路人危險跳出 / 假車禍，**路人全責** | 路人倒賠修車罰金給駕駛 |
| **1 秒前後的臨界區間**（約 0.97～1.03 秒） | 灰色地帶，**由警察隨機裁決** | 賭運氣，責任比例隨機 |

此外，**雙方的「辯解能力」會微調最終責任比例**——嘴砲越強，越能把責任往對方推。撞擊力道（車速 × 車重 × 撞擊角度）則決定賠償金額與扣血/車損的大小。

## 養成與經濟

- **金錢**：過關、賠償或碰瓷得手都能賺；用來修車、買新車、升級能力。
- **升級能力**：
  - 駕駛：煞車力道、喇叭定身時間、法庭辯解。
  - 路人：移動速度、假摔閃避（減傷）、索賠辯解。
- **車輛**（駕駛專屬）：從平民小房車，到裝甲 SUV，再到鋼鐵卡車——越重撞擊越猛，但維修越貴。
- **開局血量門檻（駕駛專屬）**：駕駛出車前，車輛耐久度必須 ≥ 50% 才能上路，不足會自動花錢修到 50%。（路人進場只看總資產是否達門檻，沒有身體血量修復機制。）
- **破產重置**：如果賠到負債（錢變成負的），或駕駛的錢不夠把車修到 50%，就觸發破產，**所有進度歸零重來**。請量力而為地碰瓷。

## 路上的突發狀況

- **🐱 突發貓咪**：偶爾有貓衝過馬路。撞到牠不扣血、不賠錢、不用上法庭——只有一聲「喵！」。
- **🛑 煞車失靈**：高關卡有機率在你踩煞車時突然失靈，煞不住。請保持安全車距。
- **📣 喇叭定身**：你按喇叭時，範圍內的路人會被嚇到定住，來不及假摔。

## 開發狀態

目前遊戲核心邏輯（碰撞判決、狀態機、存檔、隨機事件、物理、導航）已以 TDD 完成並 100% 測試覆蓋；UI/Canvas 畫面層與完整可玩關卡仍在開發中。詳細技術規格見 [`SPEC.md`](./SPEC.md)。

## 開發者快速上手

```bash
npm install      # 安裝依賴
npm test         # 執行單元測試
npm run test:coverage   # 執行測試 + 覆蓋率報告（核心層要求 100%）
```

程式架構嚴格分層：`src/core/` 為 100% 純邏輯、無副作用、可 headless 測試；UI 與平台相關程式碼放在 `src/ui/`、`src/adapters/`。
